## 二、笔试 lane（按 JD 栈映射题型）

- 栈→题型表：
  | JD 栈 | 高频题型 |
  |---|---|
  | 后端通用 | 双指针/滑动窗、链表、二叉树、堆、DP 一维/背包、二分、快排手写 |
  | 图/搜索 | BFS/DFS、拓扑排序、并查集、最短路（有岗位关键词才准备） |
  | 大数据/搜索 | 字符串处理、海量 TopK（堆/桶）、位图 |
  | 前端 | 手写 Promise/debounce、事件循环输出题、DOM 算法 |
  | 测试 | 用例设计边界、脚本题（字符串/文件处理） |
- 3-7 天倒排计划（节点=笔试日），每天固定题量+1 模板默写；
- 牛客企业题库：搜公司名+「笔试」的回忆贴，只建链接不抓内容；
- 临考 1 天：错题本过一遍，不学新东西。

## 三、八股 lane（按 JD 技术生成 checklist）

按栈生成主题清单（每个主题一句话考察口径），常见主题池：

- 语言底座：Go（schedule/channel/GC 三考）/ Java（JVM、并发包）/ Python（GIL 与并发模型）；
- 并发与分布式：锁、CAS、CAP、分布式事务、幂等（结合你 bullets 里的幂等案例）；
- 中间件：MQ（堆积/重试/顺序）、缓存（击穿/穿透/雪崩）、注册中心/网关；
- 存储：MySQL（索引/事务/主从）、Redis（数据结构/持久化/集群）、ES/向量库（按 JD）；
- 网络/OS：TCP 握手挥手、TLS、epoll、虚拟内存（视 JD 权重取舍）；
- 你的 bullets 触发：别面试官从简历反问八股——简历写了什么级别，八股就要备到什么级别。
- **升级规则**：🔴/🟠 生死题与高危题不满足于一句话口径，直接按 §九 升级为口播稿（三层结构）。

## 四、系统设计（一面含设计题 / 二面三面）

- 模板：澄清需求 → 估算（QPS/存储） → API → 数据模型 → 关键组件 → 瓶颈与演化；
- 演习题取与该公司业务近似的场景（电商选订单/秒杀、内容选 feed/去重、B 端选类目/权限）；
- 结合 01 真实经历：先画你做过的那个系统（这是最大安全区），再对虚构题。

## 五、行为面（对象：HR面/交叉面）

- 从 02 的「最强行为特征」选 1 条 + 具体实例（STAR 短版）；
- 常见题：为什么离职（06 的口径）/ 加班怎么看（如实+偏好）/ 与上级冲突（对事不对人）/
  带过人吗（按 01 如实）/ 期望团队规模；
- **禁**「抗压能力强/团队合作」类空话（03 禁词表），一律事实句替代。

## 六、薪资谈判（HR面 / OC）

1. HR面首问期望：报平台区间（06）；被追问「具体点」→ 报期望区间中位，不报底牌；
2. 现薪口径：固定现金月薪如实；不把年终/股票折算进月报口径（Offer 才算总包）；
3. band 对位：用 salary_band 之前算出的 band max 判断空间——HR 报价 < band 下限 →
   以「期望区间」礼貌还价，补一句「水平台径请明确月数与试用期折扣」；
4. OC 比较口径：base×月数 与 年包两个口径都列（涨薪算基准是年包：base 涨 20% 但月数 14→12 可能是负增长）；
5. 其他 offer 用法：**诚实**（说得出 offer 渠道与形态），不虚报竞对报价（HR 圈子小）；
6. 决策留给用户：agent 出对比表与谈判空间判断，不代谈。

## 七、反问名单（各 stage 3 问）

- 一面：团队分工与我的上手路径 / 技术挑战最近的一个 / code review 与发布节奏；
- 二面三面：业务方向未来一年的优先级 / 团队与其他方的协作边界 / 这个岗位为什么空出来；
- HR面：薪资结构细节（月数/试用期折扣/绩效系数） / 五险一金缴纳基数 / 弹性作息真实画像。

## 八、电话/视频注意事项

- 电话面：找安静处、纸笔备手边、简历打印稿（或双屏放 spec）；
- 视频面：摄像头平视、网络热点兜底、屏幕共享前关无关窗口；
- 承诺时间类问题（试用期/到岗）一律用 01 里的确定口径，当场不答应没把握的让步。

## 九、口播稿（2026-10-22 新增，技术面/HR面强制节）

**为什么**：只列「问什么」不放「怎么答」，面试现场拿到的是提纲不是武器。prep 包中的生死题/高危题必须配可背的口播稿。

**三层答案结构（每题）**：
1. **骨架（30 秒）**：一句话定调＋三点结构——面试时先报结论再展开；
2. **完整口播稿（≤120 秒，第一人称直述，可直接背）**：事实优先取 01 档案/简历 bullets 的真实证据；需要公开技术口径时用 web 资源补强（09 升级链），稿尾记「来源」行（URL＋日期，没用到就写「无外部来源，内容为档案与既有材料」）；
3. **深挖追问预案**：1-2 条追问＋一句答法（缺口一律「承认＋判断」结构）。

**防线**：
- 覆盖范围：🔴/🟠 生死题与高危题全配；普通八股 checklist 保留一句话口径即可；每场至少 3 题有完整稿；
- 稿首标注「初稿——未过你的嘴，口述一遍后按自己语言改写，别背 AI 腔」；
- 事实纪律不变：不新增经历事实；unverified 内容只进「待验证」；保密项（融资额/内部口径）绝不出现（04 红旗行）；
- 与既有定稿材料（各公司 X 号文件）冲突时，以定稿材料为准并回写到口播稿。
