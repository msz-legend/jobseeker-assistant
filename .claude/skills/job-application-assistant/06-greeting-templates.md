# 打招呼与沟通话术（Greeting & Outreach Templates）

默认动作是**打招呼语**（BOSS 等站内信场景）；正式求职信只在 JD 明确要求或外企机会时生成。
风格遵守 03（克制、量化、不谄媚、首条不报薪资）。

## 一、打招呼语（默认模板，≤3 行）

```
您好，看到贵司招聘 <JD 岗位名>。
我是 <主栈一句对位>：<一句经历对位（领域/规模）>。
近期结果：<一个数字钩子>。简历已附/可发，期待交流。
```

变体（按 01 里最贴的钩子替换第三行）：

- 规模钩子：`上家公司做到 QPS 15k 的消息网关，与贵司这个岗位的流量场景接近。`
- 领域钩子：`做过 <同域产品>，对 <JD 业务点> 的落地路径熟。`
- 成本钩子：`<项目> 削峰后机器成本降了 35%，这类账我算得动。`

**不合格自查**：两行以内写完「岗位+对位+钩子」失败即重写；带 emoji/感叹号>1/称呼「亲」→ 重写。

## 二、平台字段（BOSS「个人优势」等，100-200 字）

```
<C1 句：主栈+年限+领域对位>。<C2 句：最近一段经历的一句话结果（量化）>。
<C3 句：次栈或方法论（如稳定性/成本/带人）>。<C4 句：到岗状态与沟通意愿>。
```

- 4 句为准，≥100 字 ≤200 字（超出会裁 C3）；
- 与打招呼语、简历三处口径一致（08 的规则）；不要堆砌技术名词列表（平台字段不是技能栏）。

## 三、常见应答口径

### 期望薪资（HR 或平台字段问）

- 平台字段：填 01 期望区间 `[EXPECTED_MONTHLY_MIN]-[EXPECTED_MONTHLY_MAX]K`，月数照实；
- 聊天里被问：报区间不报点数——「我的期望在 <下限>-<上限>，具体可以聊 structure」；
- **不报底牌**（底线 `[SALARY_FLOOR_MONTHLY]` 只用于 /apply、/rank 的工具判定，永不出现在聊天）；
- 现薪被问：如实但口径报**固定现金月薪**（不含股票/报销），「详细可以在薪资证明时拉流水」。

### 到岗时间

- 在职：`[AVAILABLE_NOTICE]`（如「两周，可谈提前」）；
- 离职：随时（附上离职证明准备好的说明）。

### 离职原因（首问防线）

- 口径：向前不向后——「想做 <JD 方向>，现司 <结构限制一句>」，不对前司作负面评价；
- 不诋毁：不说现司坏话、不提某位同事；空窗按 01 `[GAP_POLICY]` 一句带过+可补充证据。

## 四、内推话术（脉脉/牛客/同事）

```
您好，我在准备贵司 <岗位> 面试，看到您是 <团队/部门> 的。
我的背景一句话：<主栈+对位>。方便的话能否内推？JD 和简历我这边都备好了。
```

- 一次一条私信；不群发抄送；被拒时回「感谢，祝顺利」收尾（关系是长线的）；
- 内推不承诺结果；以内推渠道记忆发到 tracker（channel=内推）。

## 五、跟进话术（/outcome 阈值触发）

- BOSS（5-7 天无回）：`您好，上周投递的 <岗位> 想再同步下：我上线的 <新进展/新钩子>，
  对这个岗位仍然很有兴趣，希望有机会推进。`
- 邮件（10 天）：主题 `跟进：<岗位> 申请（<姓名>）`，正文 3 行：投递信息 + 新增一个证据 + 明确请求（团队推进 or 告知节奏）；
- 猎头：按约定期直接问进度；内推（5 天）：先确认内推人是否递出，未递出的情况不催 HR。

## 六、面试感谢（当日）

```
谢谢 <面试官称呼> 今天的时间，聊 <主题 1> 和 <主题 2> 很有收获。
补充一点：您问到的 <追问点>，我后来想起 <一个补充事实/链接>。
期待后续。
```

## 七、拒信应对（好聚好散）

- 回一句感谢+保持联系（一行足够，不解释不纠缠）；
- 拒因如果 HR 说了，如实记进 tracker notes（给 /setup 校准供数据）。

## 八、例外：正式求职信（JD 明确要求 / 外企英文申请）

- 中文求职信（4 段 ≤400 字）：谁+对位 → 为什么这家（引用一个产品/新闻/技术博客）→
  一条经历当证据（含量化） → 收尾（期望什么时候聊）；
- 外企英文信：平实商务体；称呼查得到姓名就写姓名；不写 I am writing to apply 逐字开头
  （第一句直接陈述对位事实）；
- 交付形态：渠道收 DOCX/PDF 时用 build 渲染单页信（复用 base 模板的 identity 块），
  邮件直投时贴正文。

## 我的常用底稿（/setup 可填）

- 首选钩子：`[MY_DEFAULT_HOOK]`
- 团队场景偏好句：`[MY_TEAM_PREF_PHRASE]`
